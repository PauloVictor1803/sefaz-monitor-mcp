Documentação Técnica da API e Protocolo MCP

Este servidor implementa o Model Context Protocol (Streamable HTTP / SSE) e rotas REST para verificação da disponibilidade da SEFAZ nos 27 estados do Brasil.

1. Ferramentas MCP (Tools)

consultar_status_geral_sefaz

Retorna o panorama geral da SEFAZ nacional, indicando status global (UP/DOWN), número de incidentes ativos, alertas em andamento e histórico de quedas recentes.

consultar_status_uf

Retorna o status da SEFAZ para um estado específico, identificando se a UF utiliza autorizador próprio (ex: SEFAZ-BA, SEFAZ-SP, SEFAZ-MG) ou autorizador virtual (SVRS ou SVAN).

Parâmetros:

  • uf (string, obrigatório): Sigla do estado (ex: "BA", "SP", "MG", "RS", etc.)
  • tipo_documento (string, opcional): "TODOS", "NFE", "NFCE", "CTE", "MDFE" (padrão: "TODOS")

consultar_incidentes_sefaz

Lista incidentes ativos, avisos de lentidão e manutenções programadas.

Parâmetros:

  • apenas_ativos (boolean, opcional): Default true.

listar_todos_estados_sefaz

Retorna a tabela consolidada com os 27 estados do Brasil e autorizadores para um tipo de documento fiscal.

Parâmetros:

  • tipo_documento (string, opcional): "NFE", "NFCE", "CTE", "MDFE" (padrão: "NFE")
  • apenas_com_problemas (boolean, opcional): Se true, traz apenas UFs com falha ou instabilidade.

2. Endpoints REST Convencionais

Status Geral:

GET /api/status

Status por Estado:

GET /api/uf?uf=BA&tipo_documento=TODOS

Incidentes e Alertas:

GET /api/incidentes?apenas_ativos=true

Todos os Estados:

GET /api/estados?tipo_documento=NFE
