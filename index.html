🔌 Como Conectar em Qualquer Cliente MCP

Configurações para Claude, Cursor, plataformas de agentes e chamadas diretas

Adicione a configuração abaixo no arquivo claude_desktop_config.json: 

{
  "mcpServers": {
    "sefaz-monitor": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://SEU_DOMINIO.netlify.app/mcp"]
    }
  }
}

Para Claude Code, adicione via terminal: claude mcp add --transport http sefaz-monitor <SUA_URL>/mcp

No Cursor, adicione a entrada em Settings > Features > MCP ou no arquivo .cursor/mcp.json: 

{
  "mcpServers": {
    "sefaz-monitor": {
      "url": "https://SEU_DOMINIO.netlify.app/mcp"
    }
  }
}

Em plataformas que suportam Streamable HTTP (Dify, LibreChat, Chatwoot, ou assistentes corporativos):

  • Tipo de Transporte: Streamable HTTP (ou Server-Sent Events se aplicável)
  • URL do Servidor: https://SEU_DOMINIO.netlify.app/mcp
  • Cabeçalhos (Headers): Deixe vazio, ou envie Authorization: Bearer <SEU_TOKEN> se a variável AUTH_TOKEN estiver ativa.

Diretriz sugerida para incluir nas instruções de sistema do seu agente: 

Quando o usuário relatar falha, lentidão ou rejeição ao emitir documentos fiscais (NF-e, NFC-e, CT-e, MDF-e), ou perguntar sobre a disponibilidade da SEFAZ, consulte o status em tempo real com a ferramenta consultar_status_uf informando a UF da empresa. Explique com clareza se o autorizador do estado (ou o autorizador virtual correspondente) está operacional ou instável.

🛠️ Como Customizar este Projeto para Sua Marca

Este projeto é 100% agnóstico e configurável. Os seguintes pontos foram pensados para adaptação:

1. Nome e Identidade Visual

Altere a constante CONFIG.appName no script desta página e as variáveis CSS em :root para adaptar cores primárias e tipografia.

2. Variáveis de Ambiente

No arquivo .env ou painel do Netlify, defina AUTH_TOKEN para proteger requisições e PORT para alterar a porta local.

3. Repositório e Links

Atualize CONFIG.repoUrl para apontar diretamente para o seu fork no GitHub ou GitLab.
